# SM2 Enhanced

A **100% free and open source** fan-made launcher and mod for **Spider-Man 2 (2004, GameCube)**, played on the Dolphin emulator.
Every feature is free, for everyone. No paid version, no locked features.

## ⬇️ Download

**[Get the latest version](https://github.com/JohnSwingMods/sm2-enhanced/releases/latest)** → download the `.exe` under *Assets* and open it.

Windows may show a blue "Windows protected your PC" box: click **More info** and then **Run anyway** (the app isn't signed yet).

You need your **own copy of the game**. No game files are included.

## What it does

- **One-click setup:** installs Dolphin, finds your disc, sets everything up
- **HD textures:** downloads and installs the community HD packs from ModDB for you
- **40+ suits** with a 3D preview, plus an alternate suit you switch to by tapping RB
- **60 FPS, no motion blur, HUD fixed for 16:9**, graphics presets up to 4K
- **New cameras:** Modern, Amazing, Cinematic, First person (experimental), switch with R3; tune the game camera live with Spider-Cam
- **In-game menu (LB + RB):** change suits live, turn codes on and off, 3D city map with fast travel, time of day, music controls
- **Gameplay codes:** dive with L3, wall runs and web zips that keep your speed, landing momentum
- **All 5 versions:** USA, UK, Italy, Germany, France (European versions patched to 60 Hz)
- **100% save included**, any controller (Xbox, PlayStation, Switch Pro), save states with photos
- **Export** a ready-to-play mod for Android, Xbox and Mac

## Run from source

Requirements: Windows 10/11, [Python 3.11](https://www.python.org/downloads/) (64-bit), WebView2 runtime (already in Windows 11).

```
pip install -r requirements.txt
python spidey_app.py
```

Build the exe (PyInstaller, one file in `dist\`):

```
pip install pyinstaller
python build_app.py
```

## Where things are

| File | What it does |
| --- | --- |
| `spidey_app.py` | the app window (pywebview) and the in-game menu |
| `app_core.py` | engine: finds Dolphin and the game, installs mods, writes the INI files |
| `app_web/` | the pages (HTML, CSS, JavaScript) in 5 languages (`lingue.js` is generated by `crea_lingue.py`) |
| `codici_db.json` | all the cheat codes the app can turn on |
| `cam_ps4.py`, `prima.py`, `hud_ram.py`, `tuffo.py`, `muro.py`, `zip.py`, `teletrasporto.py`... | the PowerPC assembly behind the cameras, 16:9 HUD, dive, wall run, web zip and travel codes (`ppcasm.py` is a small assembler) |
| `moddb_catalogo.json` | the ModDB packs the installer knows (size, MD5, where the files go) |
| `contenuti/` | default INI files, controller profiles and other small files shipped with the app |

Code comments are mostly in Italian. The 100% save shipped in the release exe is not part of this repository.
